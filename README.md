# 📘 Address Book Application (DevOps Project)

## 📌 Overview

This project is a **CRUD-based Address Book web application** used as the primary workload in an end-to-end **DevOps CI/CD pipeline**.

It demonstrates how an application can be **built, containerized, and deployed automatically** using modern DevOps tools and practices.

---

## 🚀 Features

* Add, update, and delete contacts
* User-friendly interface for managing address data
* Backend-driven application (dynamic content)
* Designed for deployment in automated pipelines

---

## 🛠️ Tech Stack

* Application: (Java / Node.js / specify your stack)
* Containerization: Docker
* CI/CD: Jenkins
* Cloud: AWS EC2
* Infrastructure as Code: Terraform
* Configuration Management: Ansible

---

## ⚙️ DevOps Pipeline Workflow

1. Code is pushed to GitHub
2. Jenkins pipeline is triggered automatically (via webhook)
3. Application is built and tested
4. Docker image is created
5. Container is deployed on AWS EC2 instance
6. Application becomes accessible via public IP
